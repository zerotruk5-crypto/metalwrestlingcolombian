## Publicación gratuita recomendada

La versión actual es un sitio HTML estático sin backend y sin dependencias externas obligatorias.

Una opción actual para publicación es Cloudflare Pages mediante Direct Upload. La documentación oficial indica que permite subir una carpeta o un ZIP mediante arrastrar y soltar y que el sitio queda disponible bajo un subdominio `*.pages.dev`.

Pasos generales:
1. Crear/iniciar sesión en una cuenta de Cloudflare.
2. Entrar en Workers & Pages.
3. Crear una aplicación y elegir Pages / Direct Upload / Drag and drop.
4. Subir el ZIP de este proyecto.
5. Elegir un nombre de proyecto disponible.
6. Desplegar.
7. Usar la URL `https://NOMBRE.pages.dev` que entregue Cloudflare.

La URL exacta no puede determinarse antes de crear el proyecto y elegir un nombre disponible.
