# IMÁGENES DE EVENTOS — METAL WRESTLING COLOMBIAN

## Dónde colocar las imágenes

Todas las imágenes asociadas a eventos deben ir en:

`images/events/`

El sitio ya tiene una tarjeta para cada uno de estos eventos:

| Evento | Archivo que debes colocar |
|---|---|
| La muerte negra | `la-muerte-negra.jpg` |
| DEATH nation | `death-nation.jpg` |
| Alianza Metal Fest IV | `alianza-metal-fest-iv.jpg` |
| Hellraiser | `hellraiser.jpg` |
| Tormenta Andina | `tormenta-andina.jpg` |
| Capidogsmetalfest 4 | `capidogsmetalfest-4.jpg` |
| Hellbiter | `hellbiter.jpg` |
| Uscafest | `uscafest.jpg` |
| Nación en pie | `nacion-en-pie.jpg` |
| Soacha solidaria | `soacha-solidaria.jpg` |
| Metal total solidario | `metal-total-solidario.jpg` |

### Importante

No necesitas editar el HTML si mantienes esos nombres.

Simplemente reemplaza cada imagen de ejemplo por la imagen real del evento, conservando el nombre del archivo.

Por ejemplo:

`images/events/tormenta-andina.jpg`

ya contiene la imagen de **Tormenta Andina** que acabas de subir.

También dejé una segunda imagen en:

`images/pendientes/PENDIENTE_identificar_noche-heavy-metal.jpg`

No la asigné a ningún evento porque no quiero adivinar a qué evento de tu lista corresponde.

## Si una imagen tiene otro formato

Puedes usar JPG, PNG o WEBP, pero si cambias la extensión/nombre tendrás que actualizar la ruta correspondiente en `index.html`.

## Logo

`images/logo.jpeg`
